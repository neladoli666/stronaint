# TechShop

## Opis projektu

TechShop to projekt szkolny sklepu internetowego wykonany przy użyciu HTML, CSS oraz JavaScript.

Strona umożliwia przeglądanie produktów elektronicznych, dodawanie ich do koszyka oraz wyświetlanie zawartości koszyka. Dane koszyka są przechowywane lokalnie w przeglądarce za pomocą Local Storage.

## Funkcjonalności

- Wyświetlanie produktów
- Dodawanie produktów do koszyka
- Licznik produktów w koszyku
- Osobna strona koszyka
- Automatyczne obliczanie wartości zamówienia
- Responsywny wygląd strony
- Stopka z informacjami o firmie i kontaktem

## Technologie

- HTML5
- CSS3
- JavaScript

## Struktura projektu

```
projekt.html
koszyk.html
README.md
```

## Uruchomienie

1. Pobierz pliki projektu.
2. Otwórz plik `projekt.html` w przeglądarce internetowej.
3. Dodawaj produkty do koszyka.
4. Przejdź do strony koszyka przyciskiem „Przejdź do koszyka”.
